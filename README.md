# 청약레이더

청약·로또청약·청년주택·공공/장기임대·민간임대 공고를 한 곳에 모으는 사이트.

## 실행

```
npm install
npm start          # http://localhost:4320
```

`start.bat`을 더블클릭해도 됩니다. 서버가 켜져 있으면 3시간마다 자동으로 다시 수집합니다(기동 시 데이터가 1시간 이상 지났으면 바로 수집). `npm run collect`는 서버 없이 한 번만 수집합니다.

## 수집 소스

| 소스 | 내용 | 방식 |
| --- | --- | --- |
| 청약홈 APT 분양 | 민영·국민(공공) 분양, 주택형별 분양가·일정 | 목록 + 상세 페이지 |
| 청약홈 무순위·잔여세대 | 무순위(사후)·임의공급·불법행위 재공급 (줍줍) | 목록 + 상세 |
| 청약홈 오피스텔·민간임대 | 오피스텔·도시형·민간임대·공공지원민간임대 | 목록 + 상세 |
| LH 청약플러스 | 국민·영구·행복·통합공공·50년·매입임대, 공공분양·신혼희망타운 | 목록 (최근 2개월) |
| SH | 공고 게시판에서 주택 모집 공고만 제목으로 추림 | 목록 |
| 서울 청년안심주택 | 공공/민간, 최초/추가 모집 (일정은 본문에서) | JSON |
| 롯데건설 엘리스 | 롯데캐슬 뉴스테이·어바니엘 재임대·공실세대·추가모집 | JSON (일정은 제목에서) |
| 마이홈포털 API (선택) | LH·SH 외 GH·iH·지방공사 공공임대·공공분양 — LH/SH/청약홈과 겹치는 공고는 제거 | 공공데이터포털 키 + 별도 활용신청 |

마이홈포털 웹은 서버 요청을 차단(903)해서, 공공데이터포털의 `국토교통부_마이홈포털 공공주택 모집공고 조회 서비스`(같은 키, 별도 활용신청)로 받습니다. 승인 전에는 ⚙ 설정에 "승인 대기"로만 표시됩니다. LH는 브라우저 수준 User-Agent가 아니면 오류 페이지를 돌려줍니다.

## 로또청약 판별

- 키 없이: 분양가·평당가 표시, 청약홈 특이사항의 **분양가상한제** 단지를 `로또 후보`로 표시.
- 공공데이터포털 키를 넣으면(⚙ 설정 → localhost에서만 가능): 같은 시군구 최근 12개월 아파트 실거래 중앙값과 비교해 주택형별 **예상 시세·차익**과 등급(로또 / 알짜 / 시세 수준 / 고분양가)을 계산.
  - 필요한 활용신청: `국토교통부_아파트 매매 실거래가 자료`, `행정안전부_법정동코드` (둘 다 자동승인, 같은 키 사용)
  - 비교 우선순위: 같은 법정동·준공 10년 이내·전용 ±12% → 같은 시군구 → ㎡당 중앙값 환산
  - 등급: 차익 3억↑(또는 1.5억↑·30%↑) 로또, 1억↑ 또는 15%↑ 알짜, −5% 이상 시세 수준, 그 아래 고분양가
- 키는 `data/config.json`(git 제외) 또는 환경변수 `DATA_GO_KR_KEY`에 둡니다.

## 구조

```
server.js            Express: /api/notices, /api/refresh, /api/key, 정적 파일
lib/sources/*.js     소스별 수집기
lib/collector.js     병합·상세 보강·로또 판별·저장 (data/notices.json)
lib/classify.js      탭 분류·태그·접수 상태·캘린더 이벤트
lib/molit.js         실거래가·법정동코드 API (디스크 캐시)
lib/lotto.js         예상 시세·차익 계산
public/              화면 (목록·캘린더·상세 패널)
```

## 클라우드 배포

[DEPLOY_ORACLE.md](DEPLOY_ORACLE.md) — Oracle Cloud 국내 리전 무료 VM에 `deploy/oracle-init.sh` 한 번 붙여넣기로 배포 (Node + Caddy HTTPS + 30분 자동 업데이트).

## 공개 배포 시 참고

- 데이터 디렉터리는 `DATA_DIR`로 바꿀 수 있습니다. 무료 호스팅처럼 디스크가 휘발성이면 기동 때마다 1분가량 재수집합니다.
- 해외 리전 서버에서는 공공기관 사이트가 막힐 수 있으니 국내 리전을 권장합니다.
- 외부 접속자의 수동 새로고침은 15분에 한 번으로 제한되고, 키 설정은 localhost에서만 됩니다.
